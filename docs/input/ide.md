# Ide Aplikasi KosFinder

## 1. Pengguna
- **Pencari Kos**: Mengakses fitur aplikasi tanpa perlu login.
- **Pemilik Kos**: Memerlukan pendaftaran dan login untuk mengelola properti kos miliknya.

## 2. Masalah
- Informasi tempat kos masih tersebar di berbagai platform/media.
- Sulit untuk membandingkan harga serta mengecek ketersediaan kamar secara praktis dan terpusat.

## 3. Yang Diharapkan Bisa Dilakukan
- **Pencari Kos**:
  - Melihat daftar kos.
  - Mencari kos berdasarkan area.
  - Menyaring kos berdasarkan rentang harga dan fasilitas.
  - Melihat detail informasi kos.
- **Pemilik Kos**:
  - Mendaftar akun baru dan masuk ke aplikasi (login).
  - Menambah listing kos baru.
  - Mengubah informasi kos miliknya.
  - Menghapus listing kos miliknya.

## 4. Batasan
- Platform: Aplikasi Android berbasis Flutter dengan backend Supabase.
- Fitur yang **tidak mencakup** versi pertama (MVP):
  - Pembayaran online.
  - Fitur chat langsung.
  - Ulasan dan rating.
  - Rekomendasi berbasis AI.
  - Verifikasi identitas pemilik kos.
  - Upload foto kos.
  - Tampilan dan integrasi peta.
